How much does Claude Code cost?

Anthropic's own figure is about $13 per developer per active day, and $150 to $250 per developer per month. Your number depends on the model you use, how long your sessions run, and how often the cache is lost. Here is how the price is built, and how to see your own.

Updated 28 September 2026 · Serkan Korkut

The short answer

  • On a subscription, Claude Code is included in Pro at $20 a month and Max from $100 a month. You pay the plan price and work inside its 5-hour and weekly usage windows. Current plans are on claude.com/pricing.
  • On an API key, you pay per token. Across enterprise deployments Anthropic reports an average of about $13 per developer per active day and $150 to $250 per month, with 90 percent of users below $30 per active day, in the Claude Code cost docs.
  • Per prompt, the range is wide: a few cents in a short session, over ten dollars for a prompt that re-sends a long conversation.

What you pay for

Every request carries four kinds of tokens, each with its own price. Claude Code sends the whole conversation with every request, so most tokens are context, not your prompt.

Token kindWhat it isPrice against fresh input
Cache readContext the server already has cached2.5 to 10 percent, by model
InputContext sent fresh1x
Cache writeFresh context that is also stored for reuse1.25x for 5 minutes, 2x for 1 hour
OutputWhat the model writes, thinking included5x on current models

One prompt, priced

This example from Tokenmeter's demo data is a one-line prompt, "fix the failing test", late in a long session on claude-fable-5-1:

cached  3.88M × $0.25 /M  =  $0.97
fresh   0.61M × $20   /M  =  $12.28
output  12.7K × $50   /M  =  $0.63
                          =  $13.88

The prompt was one line. Almost all of the cost was 614 thousand tokens of context written to the cache again, which is what happens after a cache miss.

Why long sessions and breaks cost more

Long context. Every request re-reads the conversation. At the cached rate that is cheap per token, but a session that has been open all day carries millions of tokens on every turn.

Cache misses. The cache expires after a break longer than its lifetime: one hour on a Claude subscription, five minutes on an API key or once you draw on usage credits. The next prompt, however short, sends the full context again at the fresh price.

Compaction. Summarising a large conversation reads all of it, so it costs about as much as a cache miss. /clear costs nothing.

How to see your own cost

Inside Claude Code, run /usage. The Session block shows tokens and an estimated cost for the current session, and recent versions add a prompt cache line with the number of misses. Subscribers also see plan usage bars. It covers the current session and resets on /clear.

Across every session, Tokenmeter reads the logs Claude Code keeps in ~/.claude/projects and shows every prompt with its tokens and cost, the cache misses, cost per git commit and daily totals. Codex and GitHub Copilot CLI appear in the same view.

brew install serkankorkut/tap/tokenmeter
tokenmeter start

On Windows and Linux, pipx install tokenmeter-dashboard. All install options.

How to spend less and reduce token usage

  • Run /clear between unrelated tasks, so each request carries less history.
  • Do not revive a session that has gone cold. Start a new one with a short summary.
  • Match the model to the job. Sonnet costs a fraction of Fable or Opus for routine work.
  • Send test runs and log reading to a subagent, so the long output stays out of the main conversation.
  • Write specific prompts. "Fix the date parsing in invoice.ts" reads fewer files than "fix the bugs".

Questions

How much does Claude Code cost per month?

On a subscription, the plan price: $20 for Pro, from $100 for Max. On an API key, Anthropic reports $150 to $250 per developer per month on average across enterprise deployments. Heavy individual use can go well above that.

How much does Claude Code cost per token?

It depends on the model and the kind of token. On claude-sonnet-5, fresh input is $2 per million tokens, a cache read $0.20 and output $10. On claude-fable-5-1, fresh input is $10, a cache read $0.25 and output $50.

Is a Claude subscription cheaper than paying for the API?

For daily use, usually yes. Tokenmeter shows your plan price next to the API-equivalent value of what you used, so you can check with your own numbers.

Why did one short prompt cost so much?

Almost always a cache miss or a compaction. The prompt was short, but the whole conversation was sent again at the full price.
